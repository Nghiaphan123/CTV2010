# CTV2010 🌸

Trang web chúc mừng ngày Phụ nữ Việt Nam **20/10** gửi các chị, các bạn và các em gái thành viên **Câu lạc bộ Cộng tác viên**.

- Xem trực tiếp: https://nghiaphan123.github.io/CTV2010/
- Một file duy nhất `index.html` (HTML/CSS/JS thuần, không cần build).
- Tự hiển thị bản laptop hoặc điện thoại theo kích thước màn hình.
- Pháo hoa nhiều hình dạng (tròn, tim, sao, vòng, hoa, liễu, xoắn ốc, chữ 20/10…), chạm/click để bắn thêm.
- Tên các bạn rơi từ trên xuống và đung đưa qua lại.

Sửa danh sách tên trong mảng `NAMES` và lời chúc giữa hai dòng chú thích `LỜI CHÚC` trong `index.html`.

Chạy local: mở `index.html` bằng trình duyệt, hoặc `python -m http.server 5500`.
